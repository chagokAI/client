# Chagok Client

A real-time workspace for packaging, inventory, and procurement.

차곡 프런트엔드는 물류센터의 포장과 발주 업무를 한곳에서 다루는 웹 애플리케이션입니다.
센터 현황을 살펴보고, 물품에 맞는 박스를 관리하고, AI가 제안한 주문을 검토하는 흐름을 Vue 3와 Three.js로 구현합니다.

[서비스 바로가기](https://chagok.cloud) · [로컬 실행](docs/local-development.md) · [배포 안내](docs/cicd.md)

## ✨ 주요 기능

- **한눈에 보는 센터 현황** — 재고와 포장 상태를 3D 디지털 트윈으로 확인합니다.
- **사진 접수부터 박스 매칭까지** — 입고 사진을 분석하고 물품별 박스 매칭과 규격·재고를 관리합니다.
- **검토하고 결정하는 AI 주문** — 제안 생성 과정을 확인하고 승인·반려부터 발주 이력까지 이어서 처리합니다.
- **센터를 비교하는 본부 리포트** — 센터별 포장 효율과 운영 지침을 함께 살펴봅니다.
- **놓치지 않는 업무 알림** — 실시간 알림과 읽음 상태를 관리하고 역할에 맞는 화면을 제공합니다.

## 🗂️ 프로젝트 구성

```text
client/
├── src/
│   ├── views/          # 대시보드·박스 관리·주문·본부 화면
│   ├── components/     # 공통 UI와 화면별 컴포넌트
│   ├── api/            # API 요청과 응답 처리
│   ├── stores/         # 인증·알림·라이브 입력 상태
│   ├── composables/    # 여러 화면에서 사용하는 공통 로직
│   ├── digital-twin/   # 3D 장면과 포장 시각화
│   ├── live/           # 실시간 데이터와 재생 입력
│   └── router/         # 페이지 경로와 접근 권한
├── nginx.conf         # 정적 파일 제공과 API·SSE 프록시
└── docs/              # 개발·배포 안내
```
